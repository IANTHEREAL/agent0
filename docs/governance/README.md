# Governance (GitHub-first, v0)

This directory defines a minimal governance protocol intended to make complex work **executable, auditable, and verifiable** on GitHub:

- Roles and separation of duties: `ROLE_DEFINITIONS.md`
- Architecture Council (AC) escalation + decision protocol: `ARCHITECTURE_COUNCIL_CHARTER.md`
- GitHub Issues as SSOT task process (Stage/Execution/Verification): `GITHUB_ISSUE_SSOT_TASK_PROCESS.md`
- Mechanical enforcement (required check): `governance-lint.md`
- System behavior/contracts SoT (authoritative spec): `docs/sot/**` (changes require SA sign-off; contract changes require AC)

Reference exemplar (multi-phase pattern): https://github.com/c4pt0r/db9/issues/368
